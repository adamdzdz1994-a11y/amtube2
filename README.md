# AMTube — مُنزِّل فيديو وموسيقى للأندرويد

تطبيق أندرويد بلا إعلانات إطلاقًا، تصفّح الفيديو من داخله وتنزّله بالجودة التي تريدها (مع حجم كل جودة) أو تحوّله إلى صوت MP3 / M4A.

![icon](docs/icon_preview.png)

## ما الجديد مقارنةً بتطبيقات التنزيل المعروفة

| الطلب | ما تم |
|---|---|
| الاسم | **AMTube** |
| اللون الرئيسي الأصفر قابل للتعديل | الإعدادات ← المظهر ← **اللون الرئيسي**: 12 لونًا جاهزًا + منزلقات + رمز لون يدوي. تتلوّن كل الأزرار والأيقونات فورًا ويُحفظ اختيارك |
| أيقونات جديدة | طقم أيقونات مرسوم من الصفر (خطوط ناعمة وتفصيلة واحدة بلون التمييز) + أيقونة تطبيق جديدة (مثلث تشغيل مع شارة تنزيل) تدعم أيقونات أندرويد 13 الأحادية |
| حاجب إعلانات يوتيوب داخلي | الإعدادات ← **حاجب إعلانات يوتيوب**: مفتاح رئيسي + 3 خيارات مستقلة (إزالة الإعلانات من بيانات المشغّل، إخفاء عناصر الإعلانات، تخطي إعلانات الفيديو تلقائيًا) + حجب إعلانات المواقع الأخرى. يعمل داخل متصفح التطبيق |
| بدون إعلانات | لا توجد أي مكتبة إعلانات أو تتبّع، ولا اشتراك مدفوع (يوجد اختبار آلي يتأكد من ذلك) |
| ميزات VIP | انظر القائمة بالأسفل |
| ممنوعات | لا يوجد تنظيف مساحة ولا موفّر بطارية ولا تعزيز ولا تنظيف صور أو واتساب أو ملفات كبيرة ولا إلغاء تثبيت تطبيقات ولا شريط أدوات (يوجد اختبار آلي يمنعها) |

### ميزات VIP المتضمّنة
بما أنّ قائمة ميزات VIP في Snaptube غير منشورة رسميًا، فعلتُ المعروف منها وأكثر:
- **بلا إعلانات** نهائيًا
- **نافذة عائمة** (صورة داخل صورة) أثناء تشغيل الفيديو
- **تشغيل الصوت في الخلفية** وبشاشة مطفأة
- **تنزيل قائمة تشغيل كاملة** باختيار العناصر والجودة
- كل الجودات التي يقدّمها الموقع حتى **4K / 8K**، مع **حجم كل جودة** قبل التنزيل
- **MP3 و M4A** بنقرة
- **تنزيل الترجمة** (SRT) عند توفرها
- تنزيلات متزامنة حتى 5 مع إيقاف/استئناف
- **Wi-Fi فقط** اختياري
- وضع ليلي + أسود كامل (AMOLED)، **عربي/إنجليزي** بواجهة من اليمين لليسار
- **المشاركة من أي تطبيق**: زر «مشاركة» ← AMTube
- **تحديث محرك التنزيل** من الإعدادات بنقرة (المواقع تتغير باستمرار)

## بناء الملف APK (من المتصفح فقط — مناسب لويندوز 8.1)

ما تحتاجه: حساب GitHub مجاني. لا تحتاج تثبيت أي شيء على الحاسوب.

1. فكّ ضغط هذا المجلد.
2. في github.com اضغط **New repository** ← سمّه `amtube` ← **Create repository**.
3. اضغط **uploading an existing file** ثم **اسحب محتويات المجلد** كلها (بما فيها المجلد المخفي `.github`) إلى الصفحة ← **Commit changes**.
   > إن لم يقبل المتصفح مجلد `.github` فأنشئ الملف يدويًا: **Add file ← Create new file** واكتب الاسم `.github/workflows/build.yml` والصق فيه محتوى الملف.
4. افتح تبويب **Actions** ← **Build AMTube APK** ← **Run workflow**. (سيعمل وحده أيضًا بعد الرفع.)
5. انتظر 10–15 دقيقة ثم ادخل على آخر تشغيل ← في الأسفل **Artifacts** ← حمّل `AMTube-APK`.
6. فكّ الضغط وانقل `app-debug.apk` إلى هاتفك وثبّته (اسمح بالتثبيت من مصدر غير معروف لمتصفحك/مدير الملفات).

**إن فشل البناء** (علامة ❌): افتح التشغيل الفاشل ← الخطوة الحمراء ← انسخ آخر 30 سطرًا وأرسلها لي لأصلحها. هذا وارد لأن الكود كُتب بدون مترجم أندرويد (انظر «ما اختُبر»).

## ما اختُبر وما لم يُختبر

**اختُبر فعليًا (بمتصفح Chromium حقيقي): 40 اختبارًا آليًا**
- الواجهة كاملة: الرئيسية، المواقع (إضافة/ترتيب/حذف)، المكتبة (إيقاف/استئناف/إلغاء/حذف/تشغيل/مشاركة)، الإعدادات
- تغيير اللون الرئيسي (ألوان جاهزة/منزلقات/رمز يدوي/إلغاء/إعادة للأصفر) وأنه يبقى بعد إعادة التشغيل، وأن كل الأيقونات تتبعه
- العربية من اليمين لليسار، الوضع الليلي والأسود الكامل
- حساب الجودات وأحجامها وصف MP3 (أمثلة بأرقام معروفة)، ودفعات قوائم التشغيل
- حاجب إعلانات يوتيوب (كل جزء يعمل ويتوقف بمفرده) وزر التنزيل فوق الفيديو — على صفحة تجريبية تحاكي صفحة يوتيوب
- فحوص ثابتة: الأقواس في ملفات Kotlin، ملفات XML، المراجع بين الملفات والموارد، تطابق دوال الجسر بين الواجهة والأندرويد، غياب أي مكتبة إعلانات، غياب الميزات الممنوعة، أحجام الأيقونات

**لم يُختبر (لا يتوفر عندي Android SDK ولا Kotlin ولا هاتف):**
- ترجمة كود Kotlin (احتمال وجود أخطاء بسيطة في أول بناء)
- التنزيل الفعلي والمتصفح الداخلي والتشغيل العائم على جهاز حقيقي
- yt-dlp على الأندرويد مع يوتيوب. يوتيوب يحتاج محرك JavaScript خارجيًا (يبنيه سير العمل تلقائيًا: QuickJS). إن فشلت هذه الخطوة يبقى التطبيق يعمل مع المواقع الأخرى.
- حاجب إعلانات يوتيوب على موقع يوتيوب الحقيقي (يوتيوب يغيّر مواقع الإعلانات باستمرار، فقد يحتاج تحديثًا من وقت لآخر)

## قيود يجب معرفتها
- **أندرويد 10 فأحدث**، وهواتف 64 بت فقط (معظم الهواتف منذ 2018).
- تنزيل الفيديو من يوتيوب يخالف شروط خدمته؛ والمستخدم مسؤول عن احترام حقوق النشر. لا تنزّل إلا ما تملكه أو يُسمح لك بحفظه. لا يدعم التطبيق المحتوى المحمي بـ DRM.
- **الترخيص**: يعتمد التطبيق على مكتبات مرخّصة GPL-3.0 (youtubedl-android)، فيُوزَّع هو الآخر بنفس الترخيص. غير مناسب للنشر في متجر Google Play.
- مكان الحفظ: الفيديو في `Movies/AMTube`، والصوت في `Music/AMTube`، والترجمات في `Download/AMTube`.

## هيكل المشروع
```
app/src/main/assets/www/        الواجهة (HTML/CSS/JS): app.js, app.css, icons.js, i18n.js, formats.js
app/src/main/assets/adblock/    ytblock.js (حاجب إعلانات يوتيوب)، pill.js (زر التنزيل فوق الفيديو)
app/src/main/java/com/amtube/app/   كود أندرويد: Engine, Downloads, Bridge, BrowserHost, MainActivity, Player...
tools/make_icons.py             يولّد أيقونة التطبيق      tests/   الاختبارات
.github/workflows/build.yml     البناء السحابي للـ APK
```
تشغيل الاختبارات (يحتاج Python + Playwright + Node): `node tests/formats_test.js` و `python tests/test_ui.py` و `python tests/test_scripts.py` و `python tests/test_static.py`
